# 낯선 점술관

## 한 줄 요약
판타지 작품에서 이름만 들어 본 세계의 점술(북유럽 룬, 인도 베다 점성술)을 3분 안에 체험하며 내 운명을 점쳐 보고, 그 문화까지 알게 되는 웹 운세.

## 타깃과 상황 (누가, 언제, 왜 하는가)
- 누가: 사주·타로·MBTI 콘텐츠를 가볍게 즐기고 결과를 스토리·단톡방에 공유하는 20~30대.
- 언제: 잠들기 전, 출퇴근길, 친구가 결과 카드를 올렸을 때.
- 왜: 익숙한 운세는 식상함. **"처음 보는 방식인데 이상하게 내 얘기 같다"**는 신선함과, 룬·베다를 아는 척할 수 있는 이야깃거리.

## 검색 키워드
- 주 키워드: 룬 점 — 검색량 **미확인**
- 보조: 베다 점성술, 나크샤트라, 룬 문자 뜻, 바이킹 룬, 무료 운세 — 검색량 **미확인**
- 근거 링크: 없음. 이 기획서는 운영자 요청으로 바로 작성되어 planner의 WebSearch 조사를 거치지 않았다. 출시 전 조사 필요.

## 경험 원칙 (문구·연출 모두에 적용)
1. **용어는 풀어 쓴다.** 원어는 이름으로만, 뜻은 한국어 일상어로. 예: 나크샤트라 → "달의 집", 노른 → "운명의 세 여신", 아야남샤 → "약 24° 차이".
2. **결과마다 "완전 내 얘기잖아!" 포인트를 둔다.** 구체적인 일상 장면 문장 + 반전 정보(서양 별자리가 베다에선 다름, 내 이름의 룬 표기).
3. **의식(ritual)이 있는 연출.** 버튼 한 번이 아니라 행동이 결과로 이어지는 느낌.
4. **문화 조각을 흘린다.** 로딩·결과 곳곳에 "알고 계셨나요?" 한 줄.

## 화면 흐름
1. 시작 화면: 제목 "낯선 점술관", 부제, 방 선택 문 2개(룬의 방 / 별의 방), 곧 열리는 방 안내, 하단에 소개 글(300자 이상).
2. 입력
   - 룬의 방: 이름(텍스트, 선택, 최대 10자), 궁금한 주제(요즘의 나·사랑·일/공부·돈 중 1개, 필수, 기본값 요즘의 나)
   - 별의 방: 이름(선택), 태어난 날(날짜, 필수, 1900~2100), 태어난 시각(시:분, 한국 시간, "몰라요" 체크 시 생략)
3. 로딩(의식)
   - 룬: 주머니를 1.8초 길게 눌러 흔들기 → 돌 3개가 떨어짐 → 과거·현재·미래 순으로 탭해서 뒤집기
   - 별: 약 5초. 연도 카운터가 올해에서 태어난 해로 되감기, 27칸 별 바퀴가 돌아 달을 바늘 아래 멈춤, 베다 상식 한 줄씩 교체
   - 별(예외): 시각을 모르는데 그날 달이 다음 집으로 옮겨 간 경우 → "어느 쪽이 더 나 같나요?" 두 후보 중 고르기
4. 결과
   - 룬: 세 룬 요약 → 주제별 한마디 → 룬 3장(원래 뜻, 문화 이야기, 내 얘기 문장, 조언) → 이름의 룬 표기(이름 입력 시) → 룬의 세 줄 상식 → 면책 문구 → 버튼
   - 별: 나의 달의 집 → 공감 문장 3개 + "맞아요" 체크(개수별 반응) → 집의 상징·별·신 → 그림자와 조언 → 서양 vs 베다 별자리 반전 → 마음의 별자리(달 라시) → 지배 행성 → 면책 문구 → 버튼
5. 공유: 1080x1920 카드. 룬 = 세 룬 글자, 이름 3개, 다가올 자리 키워드, 현재 룬의 내 얘기 문장. 별 = 달의 집 이름·별명, 공감 문장 1개, "서양 ○○ → 베다 ○○".

## 결과 설계
- 룬: 24개 중 3개 무작위(중복 없음), 순서 있음. 문구는 룬 단위(24세트) × 자리 설명(3) × 주제 한마디(4).
- 별: 입력값 기반 고정. 27개 달의 집 × 12 라시(태양·달) × 9 지배 행성.
- 유형 이름: 달의 집마다 별명 (예: "왕좌의 집", "눈물방울의 집"). 최종 문구는 copywriter.

## 수익화 위치
- 광고 슬롯 후보(ads.js가 생기면): 시작 화면 소개 글 아래 1개, 결과 화면 면책 문구 아래·버튼 영역과 떨어진 위치 1개. 의식 화면에는 넣지 않는다.
- 제휴 상품: 억지스럽지 않은 카테고리 **미정** (예: 룬 스톤·천문 관련 도서). 운영자 판단 필요.

## 이번에 만들 것 / 이번에 만들지 않을 것
- 만들 것: 입구, 룬의 방, 별의 방, 공유 카드, 면책 문구, 소개 글.
- 만들지 않을 것: 뒤집힌 룬 해석, 궁합, 마야·오검 방, 광고·분석 연결(부품이 아직 없음), 결과 저장.

## 사용할 공통 부품 / 새로 필요한 부품
- 사용: share-card.js, disclaimer.js
- 새로 필요(이후): analytics.js, ads.js

## 성공 기준 (출시 2주 후)
- 방문자 수, 결과 도달률, 공유 클릭률 목표: **운영자가 정할 것** (앱 공장 첫 제품이라 비교 기준 없음)
- 추가로 볼 지표: 의식 완료율, "맞아요" 체크 수 분포(공감 문장 품질), 다른 방 이동률
- 기준 미달 시: 중단
