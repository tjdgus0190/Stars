# CLAUDE.md에 붙일 문단 — 심층상담 대화 보관 (운영자 요청 2026-11-16)

운영자 요청: "카카오 로그인하면 대화가 이어져야 해" (다른 기기·홈 화면 앱에서 같은 카카오 계정으로 로그인하면 심층상담 대화가 이어지게).

지금 CLAUDE.md 3장 면담 예외에는 "질문 글과 답은 저장하지 않는다(로그 끔)"라고 되어 있어서, 아래 문단이 들어가기 전에는 기능을 켤 수 없다.
- 화면: `products/strange-oracle/data-guide.js`의 `talkSync: "off"`. 이 값을 `"test"`(시험 주소에서만) 또는 `"live"`로 바꾸면 빌드 검사 ㉑이 CLAUDE.md에서 「심층상담 대화 보관에 한함」 문구를 찾는다. 문구가 없으면 빌드가 멈춘다.
- 서버: `/api/auth/chat`은 시험 배포(branch-deploy)에서만 열리고, 운영에서는 Netlify 환경 변수 `TALK_SYNC=live`가 있어야 열린다. 둘 다 아니면 503(off)이다.

## 붙일 위치

3장 기술 규칙의 "예외(운영자 결정 2026-11-13, strange-oracle 안내자 면담·재화에 한함)" 문단 바로 아래에 붙인다.
6장 개인정보의 "예외 5" 아래에도 붙인다.


## 켜는 순서 (운영자)

1. 위 두 문단을 main의 CLAUDE.md에 붙인다.
2. 에이전트에게 "대화 보관 켜줘"라고 한다. 에이전트가 하는 일:
   - `talkSync`를 `"test"`로 바꾼다.
   - 개인정보처리방침 제4조의7에 아래 "방침 문안"을 넣는다.
3. 시험 주소에서 두 기기(또는 두 브라우저)로 같은 카카오 계정에 로그인해 대화가 이어지는지 본다.
4. 운영에 켤 때:
   - Netlify 환경 변수 `TALK_SYNC=live`(운영 범위)를 넣는다.
   - 에이전트가 `talkSync`를 `"live"`로 바꾼다.
