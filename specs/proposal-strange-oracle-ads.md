## 1. 지금 상태와 광고 시작 조건

### 1-1. 확인한 사실

| 항목 | 지금 상태 | 확인 근거 |
|---|---|---|
| 언어 | **한국어뿐**이다. en·ja·zh(간체·번체)는 4차(글로벌, 17·18단계 뒤인 19단계 이후)다 | 결정 86·90, 17-12 |
| 결제 | 배포판은 **결제가 꺼져 있다**(`pay.mode = "off"`, 결정 94). `pay.json`은 `{"api": false}`. 페이앱 live 전이다 | specs 14-4, products/strange-oracle/pay.json |
| 광고 수익 | 사이트 안 광고는 **이미 없앴다**(결정 85, 14-2). 친구 지도에도 광고·제휴 금지(7장) | specs 14-2 |
| 분석 | GA4 코드는 남아 있지만 **측정 ID가 비어 있다**(`analytics: { ga4: "" }`). 지금은 아무것도 기록되지 않는다 | products/strange-oracle/data.js 35줄 |
| 유입 경로 기록 | GA4에 보내는 `page_location`은 주소의 `?` 뒤를 지운다. 그래서 **광고 주소에 UTM을 붙여도 GA4에 남지 않는다** | app.js 6줄 주석, common/analytics.js 39줄 |
| meta.json | status "검수통과", launched null(아직 배포 기록 없음) | products/strange-oracle/meta.json |
| 페이앱 해외 카드·해외 이용자 | **미확인.** 공식 안내에서 해외 발급 카드 결제 가능 여부를 찾지 못했다. 페이앱 쪽 안내에는 "해외결제"를 보증보험 요청 가능한 유의업종으로 적은 문장만 있다(payapp 계획서 28줄). 운영자가 페이앱 고객센터에 물어야 한다 | 7장 출처 9 |

### 1-2. 그래서 지금 광고를 돌리면

- **어느 시장이든 지금은 수익 경로가 0이다.** 결제도 광고도 없으므로 광고비는 전부 "방문만 사는 돈"이 된다.
- 서양·일본·대만 사람은 **한국어 화면**으로 들어온다. 방 Ⅰ(만신) 입력에서 거의 모두 나갈 것으로 본다(측정 전이라 비율은 미확인).
- GA4 ID가 비어 있어 **광고 효과를 잴 수단도 없다.**

### 1-3. 시장별 시작 시점 추천

| 시장 | 추천 시작 시점 | 그 전에 할 수 있는 것 |
|---|---|---|
| 한국 | **페이앱 live(배포판 결제 켜기) + GA4 ID 입력 직후** | 영상 1안 제작, 계정·픽셀 정책 결정 |
| 일본 | **ja 출시 후** | (선택) 1만원 이하 "소재 반응 시험" — 링크 없이 영상 조회만 사서 3초 시청률·완독률 비교 |
| 대만 | **zh-Hant 출시 후 + 해외 결제 수단 확정 후**(페이앱 해외 카드 미확인, 딜리헙 등은 4차에서 다시 봄) | 위와 같은 반응 시험 |
| 서양 | **en 출시 후 + 해외 결제 수단 확정 후** | 위와 같은 반응 시험 |

### 1-4. 운영자 원안("4개 시장 × 5만원")을 어떻게 쓸지

| 안 | 내용 | 판단 |
|---|---|---|
| 원안 그대로 | 지금 4개 시장에 각 5만원 | 해외 15만원은 한국어 화면 이탈로 대부분 낭비. 한국 5만원도 결제 off라 수익 0 |
| **A (추천)** | 한국 5만원은 결제 live 직후 집행. 해외 3개 시장은 각 1만원만 "소재 반응 시험"(링크 없는 조회 목표, 현지어 자막 영상)에 쓰고, 남은 각 4만원은 그 언어 출시 후 집행 | 원안의 총액(20만원)과 시장 구분을 지키면서 낭비를 막는다. 반응 시험 결과는 "4차에서 어느 언어를 먼저 낼지"의 근거가 된다 |
| B | 해외 몫 15만원을 전부 보류하고 한국만 5만원 | 가장 안전하지만 해외 반응 정보가 없다 |
| C | 한국에 20만원 몰기 | 첫 시험으로는 과하다. 한국 5만원 결과를 보고 증액 규칙(3-5)으로 늘리는 편이 낫다 |

## 2. 플랫폼 조건 (2026-10-17 확인)

### 2-1. 영상 규격

| 항목 | Instagram 릴스 광고 | Instagram 스토리 광고 | TikTok 인피드 광고 |
|---|---|---|---|
| 비율 | 9:16 권장 | 9:16 | 9:16 |
| 해상도 | 1080x1920 권장(Meta는 1440x2560도 안내한다는 2차 자료가 있음) | 1080x1920 | 1080x1920 |
| 길이 | 1초~15분(지면별 다름). 권장 6~15초, 길어도 30초 이하 | 릴스와 같은 계열. 권장 15초 이하(2차 자료) | 5~60초 지원, 권장 9~15초, 훅은 첫 2~3초 |
| 파일 크기 | 최대 4GB | 최대 4GB(2차 자료) | 최대 500MB, 비트레이트 516kbps 이상 |
| 형식 | mp4·mov | mp4·mov | mp4·mov 등 |
| 안전 영역 | 위 14%·아래 35%·좌우 6% 비우기 → 1080x1920 기준 **위 약 269px, 아래 약 672px, 좌우 약 65px** | 아래 약 20%(2차 자료) | TikTok은 고정 px 대신 안전 영역 템플릿 파일을 낸다. 아래 CTA 버튼 자리 **약 340px**를 비우라는 2차 자료가 있다. 오른쪽 아이콘 줄 폭은 **미확인**(아래 공통 박스에서 140px로 넉넉히 잡음) |
| 자막 | 무음 시청 가정, 자막 필수(우리 1-D 원칙과 같음) | 같음 | 같음 |

**공통 안전 박스(이 제안의 기본값):** 1080x1920 화면에서 위 270px, 아래 672px, 왼쪽 65px, 오른쪽 140px를 비운다. 글자·로고·핵심 그림은 가운데 **약 875x978px** 안에만 둔다. 배경 무늬는 화면 끝까지 깔아도 된다. 한 벌로 릴스·스토리·틱톡을 모두 덮기 위해 가장 넓은 값을 합쳤다. designer가 TikTok 공식 템플릿을 내려받을 수 있으면 그 값으로 다시 맞춘다(계정이 필요하면 운영자 몫).

### 2-2. 최소 예산과 5만원으로 할 수 있는 것

환율은 1달러 = 약 1,350~1,450원으로 잡았다(10월 환율은 미확인). **5만원 ≈ 34~37달러.**

| 경로 | 최소 예산 | 5만원으로 가능한 것 |
|---|---|---|
| TikTok 광고 관리자 | 광고그룹 일 예산 **20달러 초과**, 캠페인 예산을 걸 경우 일·총 **50달러 초과**(**공식**) | 광고그룹 1개를 약 **1.7일**. 캠페인 예산은 "제한 없음"으로 두고 광고그룹에만 걸어야 한다. 학습 기간이 되지 않아 시험으로는 짧다 |
| TikTok Promote(앱 안 게시물 홍보) | 하루 약 **3달러부터**, 1~7일(2차 자료) | 약 4,000~5,000원/일로 **7일 x 1~2개 영상**. 목표로 "웹사이트 방문"이 지역마다 열려 있는지는 미확인 |
| Meta(인스타그램) 광고 관리자 | 노출 기준 최적화 하루 **약 1달러**, 클릭·전환 최적화 하루 **약 5달러**(2차 자료, KRW 계정의 정확한 하한은 미확인) | 하루 5,000원 x 10일, 또는 3,000원 x 7일 + 남은 금액으로 소재 비교 |

- 2차 자료들은 "의미 있는 학습에는 하루 30~50달러 이상"이라고 한다. 즉 **5만원은 '학습'이 아니라 '소재가 먹히는지 보는 시험'** 크기다. 결제 수(전환)로 판단하기에는 표본이 작다. 그래서 3-4의 1차 판단은 선행 지표(3초 시청률·CTR·방 Ⅰ 완주율) 중심이다.
- CPM·CPC 시세는 시장·시기마다 크게 달라 이 문서에 수치로 적지 않는다(미확인). 첫 집행에서 직접 잰다.

### 2-3. 정책

| 주제 | 확인한 것 | 우리 대응 |
|---|---|---|
| 점성술·타로·운세 광고 | Meta·TikTok 모두 점성술·타로 콘텐츠를 금지하지 않았다는 플랫폼 답변 기사가 있다. TikTok 북미 광고 정책 목차(**공식**)에는 점술 항목이 없다. 지역별(일본·대만·한국) 별도 제한은 **미확인** | 금지 업종은 아니라고 보고 시작하되, 첫 집행은 소액으로 심사 통과 여부부터 본다 |
| Meta 관심사 타기팅 | Meta는 2022년에 일부 "민감 주제"(영성 관련 일부 포함) 상세 타기팅을 없앴다. 지금 "점성술" 관심사가 남아 있는지는 **미확인** | 관심사 대신 **넓은 타기팅 + 영상이 사람을 고르게** 한다 |
| Meta 개인 특성 정책(**공식**) | 광고가 보는 사람의 인종·종교·신념·나이·건강·재정 상태·**이름** 등 개인 특성을 단정하거나 암시하면 안 된다 | 자막에 "당신은 ~한 사람", "너 지금 힘들지?" 같은 **보는 사람 단정 문장 0**. 대신 제품 쪽 문장("이름 하나로 나무 문자를 새겨요", "일곱 개의 점술이 한 권의 책이 돼요")만 쓴다. 화면 안 예시 결과는 가상 이름("하늘" 같은 흔한 낱말)으로 |
| Meta 비현실적 결과 정책(**공식**) | 건강·체중·경제적 기회의 비현실적 결과 약속 금지 | 8장과 같은 방향. "인생이 바뀐다", "돈이 들어온다" 0 |
| 미성년자 | Meta는 만 18세 미만에게 나이·지역 외 타기팅을 막았다(2023) | 광고는 **만 18세 이상**만 타기팅(결제·친구 지도 14세 규칙과도 충돌 없음) |
| TikTok AI 생성 표시(AIGC) | 실제처럼 보이는 AI 생성 인물·장소·사건, 합성 음성이 들어간 광고는 AI 표시가 필요하다. C2PA 정보로 자동 감지도 한다(2차 자료, 2026-07 시행으로 정리) | B 방식(AI 클립)을 쓰면 **업로드 때 AI 표시를 켠다**. A 방식(코드로 그린 그래픽)만 쓰면 해당 없음으로 보지만, 애매하면 켠다 |
| Meta "AI 정보" 표시 | Meta 도구나 C2PA 정보로 AI 편집을 감지하면 "AI 정보" 표시가 붙는다. 실제 사람처럼 보이는 AI 인물이 나오면 "광고" 표시 옆에 바로 보인다(**공식** 블로그 + 2차 자료) | AI 실사 인물은 쓰지 않는다(아래 4장). AI 배경 클립은 표시를 막지 않는다 |
| 일본 스텔스 마케팅 규제 | 2023-10-01부터 "광고인 줄 알기 어려운 사업자 표시"가 경품표시법상 부당표시다(소비자청 고시) | 광고 관리자로 내는 광고는 "광고/PR" 표시가 자동으로 붙는다. **인플루언서·후기형 게시를 맡기면 반드시 PR 표기.** 가짜 사용자 후기 연출은 쓰지 않는다(8장 정확도 과장 금지와도 같은 방향) |
| 일본 경품표시법(우량 오인) | 실제보다 뛰어난 것처럼 보이게 하는 표시 금지 | "当たる(잘 맞는다)"·"的中" 0. 8장 정확도 과장 금지와 같다 |
| 대만 | 2024년 사기방지법으로 Meta·TikTok 등 광고 플랫폼에 **광고주 신원 확인·광고 정보 공개** 의무가 생겼다. 점술 광고 고유 규정은 **미확인** | 대만 집행 전 광고 계정의 광고주 인증(본인 확인)을 운영자가 마친다. 광고 문구에 판매자 이름이 드러나는지 확인 |

## 3. 시장별 전략

### 3-1. 공통 원칙

- **타깃 나이:** 만 18~34세 기본, 결과를 보고 35~44세 확장. 만 18세 미만 제외(2-3).
- **성별:** 나누지 않는다(8장 성별 고정관념 금지, 그리고 시험 예산이 작아 쪼개면 표본이 더 줄어든다).
- **랜딩:** 제품 입구(index.html). 프로모션 페이지(promo/)는 1-D에 기획만 있고 아직 없다. 광고 첫 단계에서는 만들지 않는다(입구가 이미 첫 3초 기준으로 다듬어져 있다, 결정 59).
- **목표:** 한국 1차는 "웹사이트 방문(랜딩 페이지 조회)" 최적화. 결제 전환 최적화는 픽셀이 있어야 해서(3-6) 지금은 못 한다.
- **기간:** 시장당 7~10일, 소재 2개 비교(A/B). 3일째 3초 시청률이 가장 낮은 소재는 끈다.

### 3-2. 시장별 표

| | 한국 | 일본 | 대만 | 서양 |
|---|---|---|---|---|

## 4. 광고 영상 기획 4안

공통 규칙
- 1080x1920, 30fps, 무음 시청 기준 자막. 글자·로고는 공통 안전 박스(2-1) 안.
- 첫 1초 안에 움직임과 자막이 동시에 나온다. 끝 2초는 로고 + "낯선 점술관" + 행동 문구.
