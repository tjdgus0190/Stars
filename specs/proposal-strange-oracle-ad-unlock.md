# 제안서: 결제 대신 "광고 보고 열기" (strange-oracle)

작성 2026-10-01 · 운영자 선택 전 단계 · 숫자는 모두 가정에 기댄 추정이다(실측 없음)

## 1. 배경
- 운영자는 아직 사업자가 없어 결제(토스)를 켤 수 없다.
- 그래서 "광고를 보면 열리는" 방식으로 유료 책을 대신할 수 있는지 검토한다.

## 2. 가능한가
| 항목 | 판단 |
|---|---|
| 웹에서 쓸 수 있는 보상형 광고 | 구글 애드센스·애드 매니저의 오퍼월(보상형 광고를 보면 콘텐츠를 여는 공식 형식)뿐이다. 한국 사이트에서 쓸 수 있는지, 신청 조건이 무엇인지는 **미확인**이라 운영자가 계정에서 확인해야 한다. 카카오 애드핏에는 웹 보상형 광고가 없는 것으로 안다(미확인). |
| 직접 만든 "광고 보면 열림" | 일반 광고를 보거나 누르게 하고 보상을 주는 것은 애드센스 정책 위반이다(무효 트래픽·클릭 유도). CLAUDE.md 7장의 클릭 유도 금지에도 걸린다. **공식 보상형 형식 말고는 하지 않는다.** |
| 선행 조건 | ① 애드센스 사이트 승인(배포된 사이트·소개 글 필요, 심사 기간 있음), ② CLAUDE.md 3장에 구글 광고 스크립트 주소 예외(결정 34 미결), ③ ads.js 공통 부품(결정 62 미결) |
| 서버 확인 | 웹 보상형 광고는 "광고를 다 봤다"는 신호가 브라우저에서만 온다. 서버가 검증할 길이 없어(앱용 서버 검증과 다름, 미확인), 마음먹으면 누구나 광고 없이 열 수 있다. 결과적으로 광고로 여는 글은 **사실상 무료 공개**가 된다. |
| 나중에 결제로 바꿀 때 | 책 전체를 광고로 열어 두면, 사업자등록 뒤 같은 책을 3,900원에 팔기 어렵다(이미 공짜로 본 사람·우회 경로). |

## 3. 대략의 예상 수입 (방문자 1명당, 원)
가정: 여섯 방 완주율 30%, 결제 전환(완주자 중) 3%, 결제 순수입 약 3,700원(수수료 뺀 값, 세금 전).
보상형: 완주자 중 40%가 광고 시청, 1인 평균 2편, 완주 1편당 5~30원(가운데 15원).
일반 배너(애드센스·애드핏): 방문자 1명당 1~6원(가운데 3원). 한 페이지 앱이라 화면을 넘겨도 페이지뷰가 늘지 않는 점을 반영했다.

| 수익원 | 방문자 1명당 (가운데 / 범위) |
|---|---|
| 일반 배너 | 3원 / 1~6원 |
| 보상형 광고로 책 열기 | 3.6원 / 1~10원 |
| 결제 3,900원 (사업자등록 뒤) | 33원 / 11~55원 |

| 월 방문자 | 배너만 | 배너 + 보상형 | 배너 + 결제 |
|---|---|---|---|
| 1,000명 | 약 3천 원 | 약 7천 원 | 약 3만 6천 원 |
| 10,000명 | 약 3만 원 | 약 7만 원 | 약 36만 원 |
| 100,000명 | 약 30만 원 | 약 66만 원 | 약 360만 원 |

- 보상형은 결제의 약 **10분의 1**이다. 같은 수입을 내려면 방문자가 약 10배 필요하다.
- 가장 크게 흔들리는 가정은 완주율과 전환율이다. 분석 도구(결정 62)가 없으면 어느 숫자도 확인할 수 없다.

## 4. 선택안
| | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 책 전체를 보상형으로 | 6/6 뒤 광고 시청 → 책 전체 열림 | 지금 당장 "열리는" 경험 | 수입 작음, 우회 쉬움, 나중 유료화 어려움, 유료 문구를 공개 쪽으로 옮기는 큰 작업 |
| B. 보너스만 보상형 (추천) | 책은 결제용으로 남기고, 방마다 숨은 장 한 장(또는 3/6 중간 결말의 덧글) 같은 작은 보너스만 광고로 연다 | 책의 값을 지킴, 보상형 반응을 미리 잴 수 있음, 작업 작음 | 수입은 더 작음 |
| C. 보상형 없이 무료판 + 배너 | 지금 무료판에 배너(결정 62)만 붙여 먼저 내보내고 숫자를 본다 | 가장 빠름, 정책 위험 적음 | "열리는" 재미 없음 |

## 5. 추천
- **C로 먼저 내보내고, 애드센스 승인 뒤 오퍼월을 쓸 수 있으면 B를 더한다.** 책 전체(A)는 나중의 결제 가치를 깎으므로 권하지 않는다.
- 어느 쪽이든 결정 34(구글 광고 스크립트 주소 예외)와 33(분석 도구)부터 정해야 시작할 수 있다.

## 6. 운영자가 정할 것
1. A / B / C
2. CLAUDE.md 3장에 구글 광고·분석 스크립트 주소 예외를 둘지 (결정 34)
3. 분석 도구 (결정 33) — 예: 구글 애널리틱스 4. 분석 이벤트에는 결과 유형 코드까지만 보낸다(6장)
4. 애드센스 가입·사이트 승인 신청 (운영자 몫, 에이전트는 계정 작업을 하지 않는다)
