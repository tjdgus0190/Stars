## 2. 안내자와 면담 (챗봇)

### 2-1. 무엇
- **누가:** 일곱 방의 안내자가 각자의 말투로 답해요. 예: 만신은 "~구먼", 시빌라는 "…"를 쓰는 말투. 브랜드 가이드 `design/strange-oracle-brand.md`를 따라요.
- **무엇을 물을 수 있나:** 내 방 결과(결과 번호)를 바탕으로 한 추가 질문. 예: "내 일간이 을목이면 올해 일은 어떻게 풀어 가면 좋아요?"
- **무엇을 근거로 답하나:** 그 방의 **우리가 쓴 해석 문장 안에서만** 답하게 묶어요(무료 data-*.js와 유료 api/_paid의 해당 칸). 고대 의미를 지어내지 않게 하려는 거예요.

### 2-2. 구조
- **서버:** Netlify 함수 `/api/talk` 하나를 둬요.
  - 보내는 것: 방 이름 + 결과 번호 + 질문 글 + 앞선 대화 몇 턴.
  - 함수가 하는 일: 안내자 설정 + 해당 해석 문장을 붙여 Claude API로 보내고, 답을 흘려 보내요(스트리밍).
- **보내지 않는 것:** 이름·생년월일·태어난 시각(결과 번호만으로 충분해요).
- **저장:** 질문 글과 답은 서버에 남기지 않아요(로그 끔). 재화 잔액만 기록해요(§3).
- **모델:** Claude Sonnet 5.5를 추천해요. 말투와 금지 주제를 지키는 품질 때문이에요. 더 싼 Haiku 5.5는 가격 미확인이라 시험 뒤 비교해요.
- **비용(추정):** 질문 하나에 입력 약 3천 토큰(해석 문장은 캐시) + 출력 약 400토큰이면 Sonnet 5.5 기준 약 $0.01(약 14원)이에요(2026-11-01 확인한 공식 가격 $2·$10/100만 토큰).
  - 하루 1,000문답이면 약 $10이에요.
  - 월 상한을 정해 두고(§6-D6), 넘으면 면담만 잠시 닫아요. 결정 없이 쓰는 돈이 생기지 않게 함수에서 막아요.
- **남용 막기:** 재화로 1회씩 차감해요. 그와 별개로 IP·기기당 하루 상한, 질문 길이 상한(300자)을 둬요.

### 2-3. 안전 (8장)
- **거절 규칙:** 건강·질병·죽음·사고·투자·도박·이별 겁주기·실존 인물·정확도 과장을 거절해요. 거절할 때는 안내자 말투로 부드럽게 돌려요.
- **긍정적 마무리:** 부정적인 이야기여도 마지막은 실행 가능한 긍정적 조언으로 끝나게 해요.
- **위기 신호:** 자해·위기 표현이 나오면 상담전화 안내 한 줄을 내고 면담을 멈춰요.
- **출시 전 시험 세트:** 금지 주제 30문항 + 일반 70문항으로 qa-reviewer가 통과 기준을 확인해요.

### 2-4. 규칙·법 (운영자 결정 필요)

| 항목 | 지금 규칙 | 필요한 결정 |
|---|---|---|
| 서버 | 3장: 결제·지도·카카오 예외만 있음 | "면담 함수" 예외 추가 |
| 개인정보 | 6장: 질문 글은 어디에도 보내지 않음(시빌라 약속) | 면담 화면에 한해 질문 글을 외부(Anthropic, 미국)로 보내는 예외. 동의 화면, 국외 이전 안내, 만 14세 미만 제외, 보관 안 함 |
| **AI 고지** | build-dist ⑯: 공개 파일에 "AI·인공지능·생성형" 등 0건 | 인공지능기본법(2026년 1월 시행)의 생성형 AI 고지 의무에 해당할 가능성이 높아요(법적 판단은 운영자 확인). 면담 화면에 "생성형 AI가 답해요" 고지를 넣으려면 ⑯을 면담 화면에 한해 풀어야 해요 |
| API 키 | 키는 코드·문서에 쓰지 않음 | 운영자가 Netlify 환경 변수 `ANTHROPIC_API_KEY`를 넣음 |

## 3. 재화 (가칭 "별가루" — 이름은 copywriter가)

### 3-1. 얻는 법 (무료)

| 방법 | 양(안) | 하루 상한 |
|---|---|---|
| 오늘의 신탁 받기 (매일 방문) | 3 | 1번 |
| 연속 방문 7일 | +10 | 주 1번 |
| 방 하나 처음 완주 | 5 | 방마다 1번(최대 35) |
| 결과 이미지·카카오 공유 | 2 | 3번 |
| 무료 도구 사용 | 1 | 3번 |
| 보상형 광고 보기(선택, §5) | 3 | 5번 |

### 3-2. 쓰는 곳

| 쓰임 | 값(안) |
|---|---|
| 안내자 면담 질문 1회 | 5 |
| 캐릭터 도감 카드의 숨은 이야기 펼치기 | 10 |
| 오늘의 신탁 한 줄 더 받기 | 3 |

책·신년운세 구매자에게는 재화를 보너스로 줘요(예: 30). 책 판매를 깎지 않고 오히려 묶는 장치예요.

### 3-3. 돈으로 사게 할까 (법적 주의)
- 재화를 돈으로 충전해 쓰게 하면 전자금융거래법의 **선불전자지급수단**에 해당할 수 있어요(등록·환불 의무). 확인은 운영자가 해야 해요.
- **추천:** 정식판에서는 재화를 **무료로 얻기만** 하게 해요. 돈을 받는 것은 지금처럼 **단건 상품**으로만 해요. 예: "면담권 10회" 2,900원을 페이앱으로 결제하면 열람 코드처럼 면담권 코드를 줘요(재화가 아니라 이용권).

### 3-4. 저장
- **비로그인:** 이 기기 localStorage. 재화 잔액은 입력값이 아니라서 6장에 걸리지 않아요.
- **카카오 로그인:** 기존 계정 기록(결제 기록과 같은 저장소)에 잔액·도감·연속 방문을 둬요.
- 위조 방지: 면담 차감은 서버에서만 해요. 비로그인 재화로 면담하려면 로그인이 필요하게 할지 §6에서 정해요.

- **그림** (§6-D4): CLAUDE.md 8장상 직접 만들었거나 상업적 이용이 확인된 것만 쓸 수 있어요.

## 5. 광고 — "콘텐츠마다 따로"
두 가지로 읽혀서 둘 다 준비해요(어느 쪽인지 §6-D5).

1. **바깥 광고(메타·구글 광고 집행)를 콘텐츠마다**
   - 콘텐츠마다 착지 주소를 따로 둬요(`/manse/`, `/nakshatra/`, 면담, 오늘의 신탁, 전설 기록).
   - utm 캠페인 값도 따로 둬요(analytics 허용 목록에 추가).
   - 콘텐츠별 광고 영상·이미지는 지금처럼 marketing/에서 만들어요.
2. **사이트 안 광고(애드센스·애드핏)를 콘텐츠 페이지에**
   - 지금은 꺼져 있어요(build-dist가 ads.js를 배포 폴더에서 뺌).
   - 켜면 안내·도구·전설 기록 페이지에만 넣어요. 7장 규칙대로 한 화면 2개, 결과·버튼 옆 금지예요.
   - 입구·일곱 방·책·결제·지도·면담 화면에는 넣지 않아요.
   - 보상형 광고(재화 지급)는 3장 구글 예외 범위예요.
   - 계정·심사는 운영자가 해요.
