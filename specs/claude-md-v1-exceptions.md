# CLAUDE.md에 붙일 예외 문안 (정식판 v1, 2026-11-13 운영자 결정) — 운영자가 검토 후 직접 추가

에이전트는 CLAUDE.md를 고치지 않는다. 운영자가 아래 문단을 해당 장 끝에 붙여 넣으면, 그 뒤에 서버 함수·재화 결제·고지 문구를 개발한다.

## 3장 기술 규칙 — 서버 예외 추가
- 예외(운영자 결정 2026-11-13, **strange-oracle 안내자 면담·재화에 한함**): 면담 답변을 위한 서버리스 함수 하나(`/api/talk`)와 재화 잔액·거래 기록을 결제 기록과 같은 저장소에 둘 수 있다.
  - 면담 함수는 방 이름·결과 번호·질문 글·앞선 대화 몇 턴만 받아 Claude API로 보내고 답을 돌려준다. 질문 글과 답은 저장하지 않는다(로그 끔).
  - 이름·생년월일·태어난 시각·성별은 보내지 않는다.
  - API 키는 환경 변수(ANTHROPIC_API_KEY)에만 둔다. 월 비용 상한을 함수에서 강제하고, 넘으면 면담만 닫는다.
  - 서버가 응답하지 않거나 상한에 닿아도 면담만 멈추고 나머지는 동작한다.
  - 재화: 잔액·거래(얻음/씀/충전/환불)·시각만 저장한다. 유료 재화는 카카오 로그인 계정에만 쌓는다.

## 6장 개인정보 — 예외 5 추가
- 예외 5(운영자 결정 2026-11-13, **strange-oracle 안내자 면담에 한함**): 면담 화면에서 이용자가 직접 적어 보낸 질문 글은 면담 함수를 거쳐 Anthropic(미국)으로 보낼 수 있다.
  - 동의 화면은 두지 않고, 개인정보처리방침에 국외 이전 항목(이전 항목·국가·업체·목적·보관 기간)을 적는다.
  - 질문 칸에 "이름·연락처 같은 개인정보는 적지 마세요"를 표시한다. 이용약관에 면담은 만 14세 이상이라고 적는다.
  - 분석 이벤트에는 방 이름과 단계 이름만 보낸다(질문 글·답 금지).

## 7장 수익화 — 재화 추가
- 재화(가칭 별가루)는 무료로 얻거나 충전해 살 수 있다. 무료 획득량은 운영자가 정한 상한을 넘지 않는다.
  - 충전은 페이앱 단건 결제로, 결제 전에 양·가격·환불(쓰지 않은 유료 재화 7일 청약철회)을 보여 준다.
  - 재화는 이 서비스 안에서만 쓴다(현금화·양도 없음).

## 안내자 면담 켜는 순서 (운영자, 2026-11-13 개발 완료 · 지금은 꺼짐)
지금 상태: 함수 `/api/talk`(netlify/functions/talk.mjs, 로직 netlify/lib/talk.js·talk-prompt.js)와 화면 `/talk/`가 있지만, 화면 `products/strange-oracle/data-guide.js`의 `talkMode: "off"`라 질문을 어디에도 보내지 않고 "면담실은 곧 열려요"만 보인다. 함수도 아래 환경 변수가 없으면 503(off)이다. 시험은 모의 서버(가짜 모델)로만 했다.

1. 위 3장·6장·7장·⑯ 문단을 CLAUDE.md에 붙여 넣는다(⑲ 빌드 검사가 "안내자 면담" 문구를 찾는다. 없이 켜면 빌드가 멈춘다).
2. Netlify 환경 변수(화면에서 직접, 코드·문서에 쓰지 않음):
   - `ANTHROPIC_API_KEY` — Anthropic 콘솔에서 만든 키
   - `TALK_MONTHLY_USD` — 월 비용 상한(달러, 예: 50). 이 값을 넘으면 그달 면담만 닫힌다(추정 비용 기준)
   - `TALK_MODE` — `live`
   - (선택) `TALK_MODEL` — 기본 `claude-opus-5-5`(입력 $4·출력 $20 / 100만 토큰, 질문 하나 약 2~3센트 추정). `claude-sonnet-5-5`로 바꾸면 약 절반(제안서 2-2 추천안). 값은 운영자가 정한다.
   - Anthropic 콘솔에서도 월 지출 한도를 걸어 두면 이중 안전장치가 된다.
3. 개인정보처리방침·이용약관에 국외 이전(Anthropic, 미국)·면담 만 14세 이상·생성형 인공지능 고지를 넣고(v1-E에서 문안 준비), 사이드바 「안내자와 면담」 아래 한 줄 고지를 붙인다(⑯ 예외가 생긴 뒤 에이전트가 넣는다).
4. `talkMode`를 `"live"`로 바꿔 배포한다.

남은 확인(미확인): Anthropic API 데이터 보관 조건, 실제 모델로 금지 주제 30문항·일반 70문항 시험(키가 있어야 함, 비용 발생 — 운영자 승인 뒤).
