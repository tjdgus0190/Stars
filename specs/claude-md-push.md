# CLAUDE.md에 붙일 문단 — 웹 푸시 알림 (2026-11-16, 운영자 요청)

운영자가 아래 문단을 CLAUDE.md에 붙여 넣은 뒤 Netlify 환경 변수 `PUSH_MODE`를 넣으면 알림이 켜진다. 에이전트는 CLAUDE.md를 고치지 않는다.

## 3장 기술 규칙에 붙일 문단

```
- 예외(운영자 결정 2026-11-16, **strange-oracle 웹 푸시 알림에 한함**): 「오늘의 신탁」 아침 알림을 위해 서버리스 함수(/api/push/*, 예약 함수 push-daily)와 저장소 하나(strange-oracle-push)를 둘 수 있다.
  - 저장은 알림 주소(브라우저가 만든 endpoint)·등록 시각·마지막으로 보낸 시각뿐. 카카오 계정·입력값과 잇지 않는다.
  - 알림은 내용 없는 빈 알림으로 보내고, 문구는 휴대폰의 서비스 워커가 공개 문구 파일로 만든다(알림 서버로 문구·개인정보가 가지 않음).
  - 알림 끄기 → 즉시 삭제, 알림 서버가 없어진 주소(404·410)라고 하면 삭제, 1년 동안 보내지 못하면 자동 삭제.
  - 서버 열쇠(VAPID)는 환경 변수 또는 함수가 처음 만들어 저장소에 둔 것만 쓴다(코드·문서에 쓰지 않음).
  - 서버가 꺼져 있거나 응답하지 않아도 알림만 멈추고 나머지는 동작한다.
```

## 6장 개인정보에 붙일 문단

```
- 예외 6(운영자 결정 2026-11-16, **strange-oracle 웹 푸시 알림에 한함**): 이용자가 알림 카드에서 직접 「알림 받기」를 누르고 브라우저 알림 권한을 허락한 경우에만 알림 주소를 서버에 보낸다.
  - 카드에 적을 것: 저장하는 것, 목적, 저장 위치(국가)·거쳐 가는 알림 서버, 보관 기간, 끄는 방법, 선택 사항이라 받지 않아도 모두 이용할 수 있다는 것.
  - 개인정보처리방침에 알림 항목(수집 항목·목적·보관 기간·저장 국가·삭제 방법)을 적은 뒤 운영에서 켠다.
  - 분석 이벤트에는 켬·끔 같은 단계 이름만 보낸다.
```

## 운영자가 할 것 (순서)
1. 위 두 문단을 CLAUDE.md에 붙여 넣기.
2. Netlify 환경 변수 `PUSH_MODE`:
   - 시험: `test` — 시험 배포(브랜치 배포)에서만 켜진다. 「시험 알림 보내기」로 바로 받아 볼 수 있다.
   - 운영: `live` — 매일 아침 9시(한국)에 예약 함수가 보낸다. 운영 전에 개인정보처리방침 알림 항목을 넣는다(에이전트가 문안 준비).
3. (선택) `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`를 넣지 않으면 함수가 처음 한 번 만들어 저장소에 둔다. 따로 할 일 없음.
