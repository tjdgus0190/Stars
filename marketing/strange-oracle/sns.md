# 게시 문구: 낯선 점술관 광고 영상 (한국판)

- 작성: copywriter, 2026-10-17
- 대상 영상: 1안 「일곱 문」 15초, 2안 「만신」 9초(`script.md`). 플랫폼마다 2안씩, 영상 둘 중 어느 쪽에 붙여도 되게 썼다(어울리는 영상을 표시).
- 결제가 아직 없으므로 가격·구매·유료 책 언급 0. "무료"라는 말도 쓰지 않았다(가격 표현으로 읽힐 수 있고, 결제가 열리면 문구를 다시 고쳐야 한다).
- 금지 점검: 정확도 과장("소름"·"100%"·"잘 맞는") 0, 공포·긴박감("지금 안 하면") 0, 보는 사람 단정("당신은 ~한 사람") 0 — 보는 사람에게는 질문으로만 묻는다, 실존 인물 0, 가짜 후기("내 결과는 ~였는데") 0 — 결과 예시는 "예를 들어"로만, 다른 서비스 문구 베끼기 0.
- 링크: 제품 주소(data.js `site.url`)가 아직 비어 있다. 인스타그램은 본문 링크가 눌리지 않으므로 "프로필 링크"로 안내하고, 주소가 정해지면 운영자가 프로필에 건다. 광고로 집행할 때는 광고 관리자의 링크 칸에 utm 화이트리스트 값(제안서 8장 4번)을 붙인 주소를 넣는다.
- 해시태그: 5개 이내.
